# Vismitha Portfolio V2

Premium recruiter-focused React + Vite portfolio.

## Run locally
1. Extract this folder.
2. Open a terminal in the project folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown by Vite.

The project includes a Vite React configuration and production build script. Vite's current documentation recommends `vite build` for the production bundle.

- `src/main.jsx` — portfolio content and structure
- `src/styles.css` — full visual system
- `index.html` — metadata
- `public/favicon.svg` — VK favicon
